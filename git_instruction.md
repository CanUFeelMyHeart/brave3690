# Инструкция по гиту

Узнать состояние репозитория:
```sh
git status
```

Добавить файл в отслеживаемые(индексация):
```sh
git add file
```

Чтобы сделать коммит файла:
```sh
git commit -m 'Comment'
```

Список изменений в репозитории:
```sh
git log 
или
git log --oneline #В сокращённом виде
```

Перемещение по сохранённым состояниям:
```sh
git checkout hash #Перемещение по сохранениям с указанием хеша
git checkout master #Вернуться на последнее состояние
```

Просмотреть изменение в файле:
```sh
git diff #можно добавить указание на хеш прошлого сохранения
```

Отменить все не сохраненные изменения:
```sh
git restore file
``` 

Посмотреть подключённые репозитории к проекту:
```sh
git remote -v
```

Добавить удалённый репозиторий:
```sh
git remote add name url
```

Получить изменения из удалённого репозитория:
```sh
git fetch name
```

Отправить изменения в удалённый репозиторий:
```sh
git push name
```

Удалить удалённый репозиторий:
```sh
git remote rm name
```
