## Marking the text 

To mark text with cursive, add asteriks sides (*) or underscore. For example, *like this* or _like this_.

To mark text with bold, add 2 asteriks on both sides (**) or 2 underscores. For example, **like this** or __like this__.

Alternative ways of marking the text are needed for us to be able to use both. For example, _text can be both in cursive and **bold**_.

## Lists

To mark unnumbered list, use (*)
To add unnumbered lists, mark element with an asteriks (*) or +. For example, like this:
* Element 1
* Element 2
* Element 3
+ Element 4

To add numbered lists, just add numbers in front of the elements. For example, like thid:
1. Element 1
2. Element 2
3. Element 3
