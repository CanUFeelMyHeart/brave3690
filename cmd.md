# Подсказки по комманднйо строке

Команда смены директории :
```sh
cd c:\folder_name
```
Команда отображения текущей директории MacOs, Linux:
```sh
pwd 
```

Листинг текущей директории Windows:
```sh
dir
```

Удаление файла:
```sh 
del <file_name>
```
Пример ссылки: 

Текст [Пример ссылки](http.example.com "Всплывающая подсказка")

Ветки 
```sh
git branch 
```

Доабвление новой ветки
```sh
git branch <название>
```

### Как добавлять картинки в MarkDown

Добавить ветку в ветку:
```sh
git merge <название>
```

Перемещение по веткам:
```sh
git checkout <название>
```

Отображение всех веток:
```sh
git branch
```

Удаление ветки:
```sh
git branch -d <имя ветки>
```

Отображение всех версий максимально удобно:
```sh
git log --oneline
```

Просмотреть список настроенных удалённых репозиториев
git remote

Добавление удалённых репозиториев
git remote add <shortname> <url>

Автоматически получить изменения из удалённой ветки и слить их со своей текущей
git pull

Склонировать удаленый репозиторий
git clone

Просмотр удаленного репозитория
git remote show <remote>

Удаление и переименование удалённых репозиториев
git remote rename

Отправляет свои изменения в удаленную ветку, созданную при клонировании по умолчанию
git push

Создание репозитория
git init

Сбросить весь индекс или удалить из него изменения определенного файла
git reset
