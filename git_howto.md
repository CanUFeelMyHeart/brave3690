# Подсказка по GIT

# Создание репозитория

## Основные команды

Инициализация
```sh
git init
```

Текущее состояние GIT
```sh
git status
```

Добавляет содержимое рабочего каталога в индекс
```sh
git add
```

Сохранить
```sh
git commit -m "Message text"
```

Журнал изменений
```sh
git log --oneline
```

Переключение между версиями
```sh
git checkout
```

Разница между текущим файлом и сохранением
```sh
git diff
```

Просмотр веток
```sh
git branch
```

Создать новую ветку
```sh
git branch <имя ветки>
```

Соединить ветки
```sh
git merge <название ветки>
```

Удалить соединенную ветку
```sh
git branch -d <название ветки>
```

Лог коммитов с визуализацией
```sh
git log --graph
```

## Команды удаленные репозитории

Копировать внешний репозиторий
```sh
git clone <ссылка>
```

Скачать все из текущего репозитория и слить с нашей версией
```sh
git pull
```

Отправить нашу версию репозитория на внешний репозиторий
```sh
git push
```

Команда для предложения изменений, запрос на вливание изменений в репозиторий
```sh
pull request
```

Как сделать pull request

1. Делаем fork репозитория
2. Делаем git clone своей версии репозитория
3. Создаем новую ветку и в нее вносим свои изменения
4. Фиксируем изменения
5. Отправляем свою версию в свой GitHub
6. На сайте GitHub нажимаем кнопку pull request
